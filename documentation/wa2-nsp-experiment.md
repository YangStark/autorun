# WA2 homebrew NSP experiment

The reproducible **source workflow**, validation commands, evidence, and
license notices are in
[experiments/wa2-nsp](../experiments/wa2-nsp/README.md). This experiment
extends the existing Autorun runtime with an isolated game root and direct
reads from installed Program RomFS, and includes a loader and streaming host
packager. The build still requires locally supplied game resources, runtime
toolchains, an icon, and packaging keys; those are not in this repository.
